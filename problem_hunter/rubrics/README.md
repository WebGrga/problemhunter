# Evaluation definitions

- `production.json`: default structured evaluator; offline demonstration uses explicit heuristics.
- `general-v5.json`: current opt-in universal experiment with selected-failure actor/task review.
- `general-v4.json`: frozen compatibility baseline.

Definitions are validated and snapshotted in stored evaluation metadata. Change
topic and scope for another industry, not the question definitions. Scores rank
investigation attention and are not market probabilities. Old invoice v1–v3
experiments were removed; Git history preserves them.
